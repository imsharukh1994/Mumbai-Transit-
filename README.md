# 🚆 Mumbai Transit+

> Your Smart Mumbai Travel Companion

Mumbai Transit+ is a modern Flutter application that helps commuters travel safely across Mumbai by providing real-time information about weather, waterlogging, local trains, metro, traffic, and community-reported incidents.

---

## 📱 Features

### 🌧️ Weather
- Live weather updates
- Rain forecast
- Hourly forecast
- Rain alerts

### 🚆 Local Train
- Western Line
- Central Line
- Harbour Line
- Live train status
- Delay notifications

### 🚇 Metro
- Live metro status
- Line availability
- Service updates

### 🚌 BEST Bus
- Route information
- Diversions
- Delays

### 🌊 Waterlogging
- Live waterlogging map
- User reports
- Water level indicators
- Safe route suggestions

### 🚗 Traffic
- Live traffic updates
- Road closures
- Accident alerts

### 📍 Smart Route Planner
- Fastest route
- Safest route
- Flood avoidance
- Estimated travel time

### 📷 Community Reports
Users can report:
- Waterlogging
- Fallen trees
- Accidents
- Road closures
- Traffic jams
- Train delays

### 🔔 Notifications
- Heavy rain alerts
- Flood warnings
- Train delays
- Metro disruptions
- Traffic incidents

### 👤 User Profile
- Saved places
- Report history
- Reward points
- Settings

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/yourusername/mumbai_transit_plus.git
```

Install dependencies

```bash
flutter pub get
```

Run the app

